# StreamProbe v1.0.0

AI 与流式 API 的浏览器端调试器 · **个人开源项目**

## 安装

1. 下载 `StreamProbe-Extension-v1.0.0.zip` 并解压  
2. `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序  
3. 打开任意页面 → 点击扩展图标 → **打开 Side Panel**  
4. 测试：打开包内 `demo.html`，点「本地 AI NDJSON 模拟」

## 功能

- EventSource + fetch ReadableStream 帧级捕获  
- Side Panel：连接 / 时间线 / Raw·Parsed 双栏  
- TTFB 与帧数指标  
- 导出 JSON 会话

# 门店排班（0.09）

上一版规则。和当前版（0.10）相比：

- **两班之间只要求休息 8 小时**（当前版 11 小时）：晚班 22:00 下班、第二天 06:00 上早班是允许的。
- **最多连续上 7 天**，也不要求每周至少休息一天。
- **同等条件先排时薪低的人**（当前版先排工时少的人），成本略低，但工时会集中在少数人身上。
- **没有「调换补缺」**：初排排不满的班直接记为缺口。
- 没有「统一岗位名」「开闭店检查」「均衡检查」；没有夜班次数上限、法定节假日计薪和保底工时。

材料要求、每一步的口径与当前版相同，见当前版说明。

在技能页把这一版放进草稿，用同一份员工表和班次需求试跑，可以对比两版的覆盖率、缺口、成本和每个人的班。
